# 쉬운 요약(summary) 오버라이드

`index.json` 은 **의안 slug 또는 의안번호 → PlainSummary** 매핑입니다.
공식 API 로 수집한 법안에는 FACT 만 들어 있고, 쉬운 요약은 여기에 사람이 작성해 넣습니다.

이 파일에 항목이 없는 법안은 사이트에서 **"쉬운 요약 준비 중"** 으로 표시됩니다.

## ⚠️ 이 파일이 담을 수 없는 것

이 사이트는 법안의 위헌 여부에 대해 **자체적인 판단·등급·논거를 만들지 않습니다.**
위헌 여부는 오직 헌법재판소의 공식 결정(`fact.courtStatus`, `fact.courtCaseNo`)만 표시합니다.

따라서 이 파일에는 다음을 넣지 않습니다.

- 충돌등급이나 위험도 (HIGH/MEDIUM/LOW 같은 표시)
- 위헌 측·합헌 측 논거
- "관련 헌법조항"이라는 이름으로 특정 조항을 이 법안과 연결하는 것
- 헌법재판소가 아직 결정하지 않은 사안에 대한 어떤 형태의 헌법적 예측·평가

## 형식

```json
{
  "2200101": {
    "whatItIs": "1~2줄, 법률용어 없이. 평가를 섞지 않는다.",
    "whyMade": "공식 제안이유를 쉬운 말로. 추측하지 않는다."
  }
}
```

## 작성 규칙

- `whatItIs` 는 법안이 무엇을 하는지에 대한 사실 paraphrase 다. "좋다/나쁘다/위험하다" 같은
  평가어를 쓰지 않는다.
- `whyMade` 는 공식 「제안이유 및 주요내용」에 적힌 내용만 쉬운 말로 옮긴다. 적혀 있지 않은
  동기를 추측해 채우지 않는다.
- 헌법재판소가 실제로 결정을 내리면, 그 결과는 여기가 아니라 `scripts/sync.mjs` 가 채우는
  `fact.courtStatus`/`fact.courtCaseNo` 로 반영되어야 한다 (아직 자동 수집 경로 없음 — §24 남은
  범위 참고).
